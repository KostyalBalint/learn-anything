## Az első kettő együtt

A költséghányad-emelés és a szocho-szorzó eltörlése ugyanazt a vállalkozót
érinti, és összeadódnak. Egy 45%-os sávban lévő átalányadózónál a különbség
látványos:

export const osszehasonlitas = (() => {
  const eves = (bevetel, kh, mentes, minAlap, szochoAlap) => {
    const jov = bevetel * (1 - kh);
    const szjaAlap = Math.max(0, jov - mentes);
    const jarulek = Math.max(szjaAlap, minAlap);
    const szocho = Math.max(szjaAlap, szochoAlap);
    return Math.round((szjaAlap * 0.15 + jarulek * 0.185 + szocho * 0.13) / 1000);
  };
  const rows = [];
  for (let m = 4; m <= 24; m += 2) {
    const be = m * 1_000_000;
    rows.push({
      bevetel: m,
      // 2025: 40% költséghányad, 1 744 800 mentes, szocho-alap 112,5%
      '2025': eves(be, 0.4, 1_744_800, 290_800 * 12, 290_800 * 1.125 * 12),
      // 2026: 45% költséghányad, 1 936 800 mentes, szocho-alap 100%
      '2026': eves(be, 0.45, 1_936_800, 322_800 * 12, 322_800 * 12),
    });
  }
  return rows;
})();

Az ábra főfoglalkozású, 45%-os (2025-ben 40%-os) költséghányadú átalányadózóval
számol, minimálbér-alapú minimumjárulékkal. A minimumteher alul így is nőtt — a
minimálbér 11%-os emelése miatt —, de a nagyobb bevételi sávokban a 2026-os
szabályok tartósan kedvezőbbek.

## Amit gyakran tévesen írnak 2026-ról

| Állítás | Valóság |
| --- | --- |
| „Az átalányadós költséghányad 40%" | **45%** 2026-tól |
| „A szocho alapja a minimálbér 112,5%-a" | a szorzót **2026. január 1-jétől nem kell alkalmazni** |
| „Az alanyi áfamentesség határa 18 millió" | **20 millió** 2026-tól |
| „Az átalányadóból 4 évig nem lehet visszatérni" | **12 hónap** — a 4 éves szabály 2021 előtti |
| „Az átalányadózáshoz előző évi bevételi korlát is van" | **2023 óta nincs** ilyen feltétel |
| „Az átalányadózó a bevétel 80%-a után fizet iparűzési adót" | **2023-ban megszűnt**, a sávos rendszer váltotta fel |
| „A KATA-s tételes HIPA 50 000 Ft/év" | jogcímként **megszűnt** 2023-ban (az összeg a legalsó sávban véletlenül ugyanannyi) |
| „A KATA-ban van 25 000 és 75 000 Ft-os tétel is" | csak **50 000 Ft** létezik; a nem főfoglalkozásúak eleve nem lehetnek kataalanyok |
| „Az eÁFA 2026-tól kötelező" | **önkéntes**, kötelezővé tételi dátum nincs jogszabályban |
| „A kézi számlatömb megszűnt" | **használható**, csak 4 napon belüli adatszolgáltatással jár |
